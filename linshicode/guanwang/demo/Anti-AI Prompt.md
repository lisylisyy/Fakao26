========================================================

ANTI-TEMPLATE DIRECTIVE

This is one of the most important instructions.

Never generate an AI-looking website.

Never generate a template-looking website.

Never generate something that resembles common startup landing pages.

If a layout feels predictable,
redesign it.

If a section feels generic,
reinvent it.

If a component looks like Bootstrap,
delete it.

========================================================

DO NOT USE THESE PATTERNS

Hero

↓

Three equal cards

↓

Four feature cards

↓

Timeline

↓

Testimonials slider

↓

Pricing table

↓

Footer

This is unacceptable.

Every section must have a unique composition.

========================================================

NO REPEATED LAYOUTS

Do not stack identical sections.

Avoid repeating:

left text + right image

right text + left image

grid after grid

card after card

icon after icon

Instead,

mix

storytelling

motion

depth

interaction

camera movement

3D scenes

typography

negative space.

========================================================

NO GENERIC CARDS

Do not create

rounded rectangle

icon

title

description

button

repeated six times.

Instead,

every important concept should have its own visual identity.

========================================================

NO TEMPLATE HERO

The Hero section must NOT consist of

Headline

Subtitle

Button

Background image.

Instead,

the Hero must feel like entering another world.

Users should immediately interact with the environment.

The page begins before users scroll.

========================================================

NO DECORATIVE THREE.JS

Never place a rotating cube simply because Three.js is available.

Never use floating objects without meaning.

Every 3D object must represent

connection

AI

commerce

technology

growth

globalization

or intelligence.

3D is storytelling.

Not decoration.

========================================================

NO FADE-IN EVERYTHING

Avoid the lazy animation pattern:

opacity 0

↓

opacity 1

↓

translateY

↓

done

Instead,

combine

camera movement

mask reveal

lighting

shader transition

particle transformation

depth transition

text split

perspective

physics

motion choreography.

========================================================

DESIGN AS A FILM

Scrolling is not scrolling.

Scrolling is directing a movie.

Each section is a scene.

Each animation is a camera cut.

Each transition changes the emotional state.

Think like Christopher Nolan directing a technology company.

========================================================

CREATE RHYTHM

Alternate between

fast

slow

dense

minimal

dark

bright

quiet

dynamic

Allow users to breathe.

Then surprise them again.

Never let every section have identical visual density.

========================================================

THINK IN DEPTH

Every page should contain

foreground

midground

background

lighting

fog

particles

camera

interaction

instead of a flat webpage.

========================================================

NO STATIC BACKGROUNDS

Backgrounds should evolve.

Light moves.

Particles flow.

Noise shifts.

Gradients breathe.

Camera subtly drifts.

The world never freezes.

========================================================

NO PERFECT SYMMETRY

Perfect symmetry feels artificial.

Introduce controlled asymmetry.

Unexpected compositions.

Different visual weights.

Offset layouts.

Organic rhythm.

========================================================

MICRO DETAILS

Buttons should feel physical.

Cards should have depth.

Lighting changes with interaction.

Cursor influences nearby objects.

Glass reflects light.

Typography reacts subtly.

Nothing should feel dead.

========================================================

ENGINEERING QUALITY

Never write code just to satisfy requirements.

Write production-level architecture.

Components should be reusable.

Animations should be maintainable.

Shaders should be modular.

Every decision should scale.

========================================================

SELF-CRITIQUE

Before completing any section,

ask yourself:

Would this impress Apple?

Would this impress Vercel?

Would this win Awwwards?

Would an experienced designer keep this?

If the answer is no,

redesign it.

========================================================

FINAL STANDARD

The website must not feel AI-generated.

It must feel like

a multidisciplinary team

consisting of

creative directors,

3D artists,

motion designers,

frontend engineers,

UX researchers,

shader engineers,

and brand designers

worked together for months.

Quality is more important than speed.

Beauty is more important than quantity.

Emotion is more important than decoration.

Never stop refining until the result feels unforgettable.
