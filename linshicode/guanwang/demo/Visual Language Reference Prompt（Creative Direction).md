========================================================

VISUAL DIRECTION REFERENCE

Do NOT copy any existing website.

Instead, extract the design philosophy behind each brand.

Learn their visual language rather than their appearance.

Combine these philosophies into one original experience.

========================================================

APPLE

Learn Apple's obsession with simplicity.

Large empty spaces.

Extremely refined typography.

Perfect spacing.

Perfect alignment.

Every animation has purpose.

Nothing decorative.

Everything feels intentional.

Every transition should feel invisible.

Use soft lighting.

Elegant shadows.

Premium materials.

Slow cinematic movement.

Confidence instead of excitement.

The page should breathe.

========================================================

OPENAI

Learn OpenAI's feeling of intelligence.

The interface should feel calm.

Modern.

Sophisticated.

Scientific.

Minimal.

Use subtle gradients.

Soft glow.

Fluid transitions.

AI should be represented through movement rather than icons.

Think about intelligence flowing through space.

Create curiosity instead of overwhelming users.

========================================================

VERCEL

Learn Vercel's engineering precision.

Sharp layouts.

Perfect grids.

Excellent responsiveness.

Every component feels handcrafted.

Micro interactions are extremely polished.

Hover states are subtle.

Motion is smooth.

Use typography as a design element.

No unnecessary decoration.

Engineering elegance.

========================================================

LINEAR

Learn Linear's interaction design.

Everything feels incredibly responsive.

Every hover has feedback.

Every click feels physical.

Motion easing is exceptional.

Animations are short but meaningful.

Scrolling feels premium.

Use glass.

Soft blur.

Depth.

Elegant borders.

Professional color balance.

========================================================

STRIPE

Learn Stripe's storytelling.

Scrolling should reveal information naturally.

Cards should move in 3D.

Sections should overlap.

Perspective changes while scrolling.

Use asymmetric composition.

Combine illustrations with motion.

Create momentum.

Never feel static.

========================================================

TESLA

Learn cinematic presentation.

Products feel monumental.

Use dramatic camera angles.

Lighting should guide attention.

Large typography.

Minimal interface.

Strong visual hierarchy.

Create emotional impact before showing information.

========================================================

SPACEX

Learn how to create scale.

Everything should feel vast.

Massive environments.

Slow camera movement.

Dark backgrounds.

Powerful contrast.

Large hero scenes.

Subtle motion.

Create the feeling of exploration.

========================================================

AWWWARDS

The website should never feel like a template.

Every section should introduce something new.

Every scroll should surprise users.

Avoid repeating layouts.

Avoid repetitive cards.

Avoid repetitive grids.

Create visual rhythm.

Every screen should have its own identity while maintaining consistency.

========================================================

CINEMATIC EXPERIENCE

Imagine this website as a science fiction movie rather than a business website.

Scrolling is equivalent to moving through scenes.

The camera should not simply move vertically.

Use depth.

Perspective.

Layering.

Foreground.

Midground.

Background.

Create visual storytelling.

========================================================

MOTION PRINCIPLES

Motion should feel physical.

Every object has weight.

Every transition has inertia.

Use easing curves.

Objects accelerate naturally.

Objects decelerate naturally.

No linear animations.

No robotic movement.

Everything should feel handcrafted.

========================================================

THREE DIMENSIONAL DESIGN

Do not simply place 3D models inside the page.

Instead,

merge HTML,

motion,

lighting,

particles,

camera,

shader,

and typography

into one unified experience.

3D should support storytelling.

Never use 3D only for decoration.

========================================================

LIGHTING

Treat lighting as if rendering a premium cinematic scene.

Soft rim light.

Ambient light.

HDR lighting.

Glow.

Bloom.

Volumetric feeling.

Subtle reflections.

Glass materials.

Refraction.

========================================================

COLOR

Restrained.

Premium.

Mostly monochrome.

Dark navy.

Graphite.

Soft blue.

Cyan highlights.

White typography.

Avoid saturated colors.

Avoid rainbow gradients.

Less colors.

Higher quality.

========================================================

TYPOGRAPHY

Typography is the hero.

Huge headlines.

Excellent hierarchy.

Premium font pairing.

Readable paragraphs.

Large spacing.

Elegant rhythm.

Never overcrowd content.

========================================================

INTERACTION

Buttons should react physically.

Cards should respond to cursor.

Background should react to movement.

Camera should subtly shift.

Particles should respond to proximity.

Scrolling should affect lighting.

The page should always feel alive.

========================================================

EMOTIONAL GOAL

The visitor should experience this sequence:

Curiosity

↓

Wonder

↓

Immersion

↓

Trust

↓

Innovation

↓

Global Vision

↓

Confidence

↓

Action

========================================================

ABSOLUTELY AVOID

Bootstrap feeling

Corporate templates

Stock illustrations

Static sections

Traditional timelines

Traditional icon grids

Heavy gradients

Cheap glassmorphism

Overuse of neon

Random floating shapes

Generic hero sections

Generic cards

Generic testimonials

Anything that looks like a startup template.

========================================================

FINAL DESIGN PRINCIPLE

Design less.

But make every element exceptional.

Every pixel should have intention.

Every interaction should tell a story.

Every animation should communicate quality.

The website should feel like a premium digital product instead of a marketing website.

When visitors close the website,

they should remember the experience,

not merely the information.
