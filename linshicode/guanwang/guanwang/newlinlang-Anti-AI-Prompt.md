========================================================

ANTI-TEMPLATE DIRECTIVE — LinknLatch newlinlang.html

This is one of the most important instructions.

Never generate an AI-looking website.

Never generate a template-looking website.

Never generate something that resembles a startup landing page or an investor-deck-export.

If a layout feels predictable, redesign it.

If a section feels generic, reinvent it.

If a component looks like Bootstrap or shadcn, delete it.

========================================================

NO DARK-AI CLICHÉ

This brand is paper, ink and stamps — NOT plasma, glass and neon.

Forbidden, without exception:

glassmorphism

neon glow

particle fields

3D globes

gradient meshes

dark hero with floating orbs

typing-cursor "AI" gimmicks

Matrix / circuit-board / neural-network imagery

"AI" does not need to look like science fiction. Here, AI looks like a signed contract and a paid invoice.

========================================================

NO DESIGN-SYSTEM VIOLATIONS

blur on box-shadows — forbidden (0px blur only)

gradient section backgrounds — forbidden

colors outside the token palette — forbidden

fonts other than Bebas Neue / DM Sans / Caveat — forbidden

pure #000 or pure #FFF as page background — forbidden

thin 1px borders on cards — forbidden (2px / 3px only)

arbitrary border-radius values — forbidden (follow the scale)

The design system is a contract, not a suggestion.

========================================================

DO NOT USE THIS PATTERN

Hero

↓

Three equal cards

↓

Four feature cards

↓

Stats row

↓

Testimonials

↓

Pricing table

↓

Footer

This is unacceptable.

The OLD site (linlang.html) already suffers from this: card grid after card grid after card grid, every section revealed with the same fadeUp.

The NEW site exists to fix exactly that.

========================================================

NO REPEATED LAYOUTS

No two adjacent sections may share the same layout skeleton.

Avoid repeating:

grid after grid

card after card

left-label + right-list rows stacked forever

Instead, alternate between:

typographic monuments

connected step sequences

physical stacks (the 5-layer diagram)

marquee bands

trading-card spreads

side-by-side decisions

black drops

Each section is a magazine spread with its own composition idea.

========================================================

NO GENERIC CARDS

Do not create

rounded rectangle

icon

title

description

repeated six times.

Every important concept gets its own visual identity:

licenses are collectible stamps,

metrics are counting monuments,

layers are stacked paper,

team members are trading cards,

pricing tiers are tilted tags,

the deal is a two-door choice.

========================================================

NO FADE-IN EVERYTHING

Forbidden lazy pattern: opacity 0 → opacity 1 → translateY → done, applied uniformly to every .rev element.

Instead choreograph:

staggered stamp-ins

rotate-and-settle

count-up numbers

layer-by-layer stack builds

width-growing fund bars

direction changes per section

Reveals must feel designed per section, not applied globally.

========================================================

NO EMOJI ICONS · NO FAKE GRAPHICS

No emoji as icons anywhere.

No stock-style illustrations.

No placeholder images.

Icons, when needed, are inline SVG drawn in the ink language (2px black strokes) — or typographic marks (★ · ▸ · ↓) used deliberately.

========================================================

NO FAKE DATA

Every number, brand name, license, bio fact and price comes from linlang.html.

Do not round differently, do not embellish, do not invent testimonials or logos.

Candor is part of the brand ("坦诚表达：还不算特别高" stays candid).

Both languages must carry identical facts.

========================================================

DESIGN AS AN EDITORIAL MAGAZINE

Scrolling is page-turning.

Each section is a spread with one clear idea.

Alternate loud and quiet, dense and airy, cream and black.

Let the reader breathe after every drop.

Think like an art director closing a print issue, not a developer stacking components.

========================================================

MICRO DETAILS

Every interactive element lifts on hover and presses on click.

Stickers sit at slight angles and straighten when touched.

Focus states are visible and on-brand (green offset ring).

The scroll progress bar is a thin green thread.

Nothing on the page feels dead under the cursor.

========================================================

ENGINEERING QUALITY

Semantic HTML. One h1. Ordered headings.

All tokens as CSS custom properties — no magic hex values in rules.

Component classes, no duplicated style blocks.

One IntersectionObserver. rAF for count-ups. Zero console errors.

The zh/en dual-language structure covers 100% of visible text.

prefers-reduced-motion honored completely.

========================================================

SELF-CRITIQUE

Before finishing any section, ask:

Would Gumroad's design team keep this?

Does it still feel 100% LinknLatch (cream / ink / green / pastel)?

Is this section's composition different from its neighbors?

Is every fact traceable to linlang.html, in both languages?

Would an investor screenshot this section and send it to a partner?

If any answer is no, redesign it.

========================================================

FINAL STANDARD

The website must not feel AI-generated.

It must feel like a multidisciplinary studio —

an art director,

a type designer,

a motion designer,

a frontend engineer,

and a very confident founder —

spent a month sweating every spread.

Quality over speed.

Character over decoration.

Candor over hype.

Never stop refining until it feels unforgettable.
