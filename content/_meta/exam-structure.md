# 法考客观题考试结构

## 总体

- 卷一 + 卷二，**各 150 分**，合计 **300 分**
- 合格线：**180 分**
- 每卷 100 题，时限 **180 分钟**
- 题型：
  - 单项选择 50 题 × 1 分 = 50 分
  - 多项选择 35 题 × 2 分 = 70 分
  - 不定项选择 15 题 × 2 分 = 30 分

## 卷一（公法卷 + 三国法 + 理论法）— 150 分

| 学科 | 大致分值 | 目录 |
|---|---|---|
| 中国特色社会主义法治理论 | ~8 | content/theory/rule-of-law/ |
| 法理学 | ~15 | content/theory/jurisprudence/ |
| 宪法 | ~15 | content/theory/constitution/ |
| 中国法律史 | ~5 | content/theory/legal-history/ |
| 司法制度和法律职业道德 | ~10 | content/theory/ethics/ |
| 国际公法 | ~15 | content/international/public/ |
| 国际私法 | ~15 | content/international/private/ |
| 国际经济法 | ~15 | content/international/economic/ |
| 行政法与行政诉讼法 | ~30 | content/administrative/ |
| 刑法（卷一部分） | ~20 | content/criminal/ |
| 刑事诉讼法（卷一部分） | ~5 | content/criminal-procedure/ |

> 注：刑法、刑诉、行政法实际可能分散到卷一/卷二两卷，以官方大纲为准。

## 性价比策略

- **优先攻克**：三国法（~45 分，重背诵）+ 理论法（~53 分，重理解+背诵） — 性价比最高
- **稳扎稳打**：民事诉讼法（含仲裁）、行政法 — 体系清晰，规则导向
- **硬骨头**：民法、刑法、商经法 — 知识点零碎、综合题难，分值大不可放弃
- **目标**：三国法 + 理论法拿到 80%（~78 分），其他学科平均 55%（~110 分） ≈ 188 分，过线
