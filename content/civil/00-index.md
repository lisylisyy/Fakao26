# 民法

卷二最大分值学科，约 45 分。**硬骨头**之一，知识点多、综合题难。

## 知识体系（占位，按民法典编次）

### 总则编

- [ ] `civ.basic-principles` 基本原则
- [ ] `civ.natural-person` 自然人（民事权利能力、行为能力、监护、宣告失踪/死亡、个体工商户）
- [ ] `civ.legal-person` 法人与非法人组织
- [ ] `civ.civil-rights` 民事权利体系
- [ ] `civ.juridical-act` 民事法律行为
  - [ ] `civ.expression-of-intent` 意思表示
  - [ ] `civ.juridical-act-validity` 民事法律行为效力（有效、无效、可撤销、效力待定）
- [ ] `civ.agency` 代理
- [ ] `civ.responsibility` 民事责任
- [ ] `civ.limitation` 诉讼时效与期间

### 物权编

- [ ] `civ.property.general` 物权通则
- [ ] `civ.property.ownership` 所有权
- [ ] `civ.property.usufruct` 用益物权
- [ ] `civ.property.security` 担保物权（抵押、质押、留置）
- [ ] `civ.property.possession` 占有

### 合同编

- [ ] `civ.contract.general` 合同通则
- [ ] `civ.contract.formation` 合同订立
- [ ] `civ.contract.validity` 合同效力
- [ ] `civ.contract.performance` 合同履行
- [ ] `civ.contract.security` 合同保全（代位权、撤销权）
- [ ] `civ.contract.modification-transfer` 变更与转让
- [ ] `civ.contract.termination` 权利义务终止
- [ ] `civ.contract.breach` 违约责任
- [ ] `civ.contract.typical` 典型合同（买卖、租赁、借款、承揽等 19 类）
- [ ] `civ.contract.quasi` 准合同（无因管理、不当得利）

### 人格权编

- [ ] `civ.personality.reputation-honor` 名誉权、荣誉权
- [ ] `civ.personality.privacy-info` 隐私权、个人信息保护
